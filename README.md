# 二度寝防止アプリ（高校の卒業制作）

Xcodeを用いて開発している二度寝防止iOSアプリです。

不快な大音量アラームによる不快な目覚めではなく「脳と身体に適度な負荷をかける」ことで

自然で心地よい目覚めを促すことを目指しています。


## プロジェクト概要

* 開発期間： 2026/4〜現在

* 開発人数： 1人　個人開発

* プラットホーム： iOS / macOS

* 担当領域：企画、UI/UXデザイン、プログラミング（機能実装）


## 特徴・工夫したこと

機械的・自律的なアプローチを組み合わせ、９種類のミッションがランダムに発生させることで

飽きずに楽しく目が覚める工夫をしています。

## 脳と身体を段階的に起こす「９つのミッション（一部）」

身体の覚醒（運動・血流促進）
  
* スマホシェイク：スマホを100回振る（軽い運動で血流を促す）

* スライド：5回スライドする（手元の確実な動作を要求）

脳の覚醒（記憶・単純作業）

* １００回タップ：画面を100回タップする単純作業で意識を集中させる

脳の覚醒（思考・認知活動）

* 昨晩の晩御飯を入力：前夜の記憶を思い出すことで脳を活性化する

* 提示文字列の入力：画面に表示されたランダムな文字列を正確に入力する
